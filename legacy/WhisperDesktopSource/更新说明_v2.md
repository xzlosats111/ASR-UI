# v2 更新：完整功能恢复、中文修复与批量文件转写

## 必须按此方式更新

此 ZIP 是给你当前已推送过的源码目录的**覆盖更新包**，不是新的独立仓库。

1. 退出正在运行的 `WhisperDesktop.exe`；
2. 把 ZIP 解压到原来的源码根目录：`WhisperDesktop-JapaneseSRT-Source`；
3. Windows 询问时选择“替换目标中的文件”；
4. 在该根目录双击 `一键推送更新到GitHub.cmd`；
5. 等 GitHub Actions 中 **Build Japanese SRT Tool** 构建完成，下载新的 `WhisperDesktop-x64`。

> 不要把此更新 ZIP 解压到一个完全新的空目录后直接推送：该目录没有你先前推送所用的 `.git` 历史，GitHub 会拒绝无关历史。

## 改了什么

- 修正 C++ 源文件的 UTF-8 BOM，解决“多语言”“开始转写”等运行时中文乱码；
- 恢复完整原界面和功能：语言选择、翻译、输出格式/字幕类型、手动输出位置、GPU 高级设置、调试控制台、文件转写、实时麦克风转写；
- 默认语言改为日语、默认输出格式改为 SRT，但不锁定，可以随时更改；
- 启动时固定先显示模型选择窗口，不会自动加载上次模型；
- 文件选择器增加常见音视频格式，并支持 Ctrl / Shift 多选；多选文件会顺序转写，自动在各源文件同目录输出同名字幕。
