# v3 更新：FLV 兼容和批量任务不中断

## 更新内容

- **FLV 支持**：当 Windows Media Foundation 无法打开 `.flv` 时，程序自动调用和 `WhisperDesktop.exe` 放在同一目录的 `ffmpeg.exe`，将音轨转为临时 16 kHz 单声道 WAV 后继续识别。
- **FFmpeg 自动随成品提供**：GitHub Actions 构建会下载并将 `ffmpeg.exe` 及许可证放入 `WhisperDesktop-x64` artifact。运行时不要把 `ffmpeg.exe` 与主程序分开。
- **批量转写容错**：某个文件无法解码、无法写入或模型运行失败时，批量任务会记录该文件、删除不完整输出，并继续后面的文件；全部完成后统一提示已处理数和失败数。只有所有文件都失败时才显示失败详情。

## 更新方式

1. 解压 `WhisperDesktop-v3-FLV与批量容错更新.zip` 到一个**新的更新包文件夹**，不要直接解压到旧源码目录。
2. 双击该新文件夹里的 `从更新包一键覆盖并推送.cmd`。
3. 该脚本会自动覆盖 `C:\Users\111\Desktop\WhisperDesktop-JapaneseSRT-Source`，使用 `127.0.0.1:10809` 代理提交并推送。
4. GitHub Actions 完成后，重新下载 `WhisperDesktop-x64`。请使用该 artifact 内的全部文件，不要单独只复制 EXE。
