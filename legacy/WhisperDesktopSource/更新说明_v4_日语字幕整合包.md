# v4 更新：Qwen + Parakeet 日语 SRT 整合包

## 这次增加了什么

在保留完整 `WhisperDesktop v3` 的前提下，成品包会多出一个 `JapaneseSubtitleHub` 文件夹：

- **Qwen 高质量日语模式**：Qwen Japanese Anime/Galgame Q4_K + Qwen ForcedAligner Q4_K，面向动画、galgame / 视觉小说式日语对白；
- **Parakeet 快速日语模式**：Parakeet Japanese Q8_0，使用原生时间码；
- **图形化上游下载列表**：显示引擎 / 模型是什么、用途、大小、上游来源和许可证；
- **代理开关**：默认启用 `http://127.0.0.1:10809`，可取消勾选直连；代理同时传给 CrispASR 的首次自动 VAD 模型下载；
- **FFmpeg 转换**：新模式会先把视频 / 音频转换为临时 16 kHz 单声道 WAV，因此常见视频、FLV 等都能进入新引擎；
- **批量容错**：新模式逐文件执行；任意一个转换或识别失败会记日志并继续后续文件；
- **A/B 对比输出**：Qwen 输出 `文件名.qwen-ja.srt`，Parakeet 输出 `文件名.parakeet-ja.srt`，互不覆盖；
- **原版能力不删除**：整合工具的 `Full WhisperDesktop v3` 页面直接启动原有程序，继续保留模型选择、语言、字幕 / 输出类型、实时麦克风、GPU 控制、多选批处理与 FLV 回退等全部 v3 功能。

## 第一次使用

1. 解压 GitHub Actions 产物 `WhisperDesktop-x64`，保持所有文件在同一个解压目录。
2. 打开 `JapaneseSubtitleHub\Start-JapaneseSubtitleHub.cmd`。
3. 进入 `Components and download` 页，默认选项就是推荐组合：
   - CrispASR CUDA 12.6 legacy runtime；
   - Qwen Anime Q4_K；
   - Qwen ForcedAligner Q4_K；
   - Parakeet Japanese Q8_0；
   - FFmpeg LGPL。
4. 若本机代理是 `127.0.0.1:10809`，不要改动默认代理设置；不用代理时取消勾选。
5. 下载后进入 `Japanese SRT`，先用同一个短片分别跑一次两种模式，比较两份 SRT。

默认下载约 **3.3 GiB**，建议目标磁盘至少留 **6 GiB** 空闲空间，另外按输入视频大小预留临时 WAV 与输出空间。所有模型与运行时由 GUI 直接向上游下载，**不会被提交到 Git 仓库**。

## 更新源码并推送

1. 解压本更新包到一个新的文件夹；不要直接覆盖旧源码。
2. 双击更新包里的 `从更新包一键覆盖并推送.cmd`。
3. 它会覆盖 `C:\Users\111\Desktop\WhisperDesktop-JapaneseSRT-Source`，配置 `http://127.0.0.1:10809` 代理并推送到现有 GitHub 仓库。
4. 等待 GitHub Actions 的 **Build Japanese SRT Tool** 完成，再下载 `WhisperDesktop-x64` artifact。

## 已知边界

- 本整合工具是 Windows PowerShell GUI；它不需要 Python、PyTorch 或 CUDA Toolkit。
- Qwen / Parakeet 在 GTX 1080 Ti 上的实际速度、准确率和驱动兼容性仍须在真实机器实测。当前 Linux 工作区不能编译或运行 Windows GUI / CUDA 包。
- 下载链接固定到本次确认的 CrispASR `v0.8.45` 和模型修订版本；FFmpeg 使用 BtbN 的 `latest` LGPL Windows 包。
- 许可证和模型使用条件以各上游项目及模型卡为准。Parakeet 模型卡列为 CC-BY-4.0，使用时须遵守署名要求。
